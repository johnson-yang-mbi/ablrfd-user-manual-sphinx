# SOR-04-2025

**Summary of April 2025 Revisions - Version 1.20.0.0**

Since the release of ABLRFD Version 1.19.0.0 several revision requests
and user requested enhancements have been received. This release of
ABLRFD Version 1.20.0.0 contains the following revisions and
enhancements.

**[Input Revisions]{.underline}**

1.  Having entered both a non-zero friction force and a non-zero
    temperature force on the LAB command now results in an error
    message. (Request 510)

**[Output Revisions]{.underline}**

2.  For design runs that have failed to find a solution, the smallest
    footing width with the most passing checks are reported. When no
    footing configurations have passed at least one check, no footing
    dimensions are reported. Previously, sometimes the footing with the
    most passing checks was not being reported. (Request 426)

3.  For spread and pedestal footings an Intermediate Settlement Data
    output report has been added to provide values used to compute the
    elastic settlement. (Request 484)

4.  The CFG command parameters have been processed to set global output
    variables before any output has been written to the output file.
    Previously, the global output variables affected by the CFG command
    were not set until the Input Summary was printed. (Request 504)

5.  The Input Parameter Names, reported in the Input Commands Output,
    has been increased to allow longer names to be used. This will allow
    the Parameter Names to more closely match the names used in Chapter
    5 and in the tab pages for Engineering Assistant. (Request 507)

6.  Average Load Factors have been removed from the Foundation Force
    output results for spread footings and footing on piles. (Request
    511)

7.  The PED Command input parameter, DESIGN OPTIMIZATION, has been added
    to the Input Summary output. For analysis runs, the DESIGN
    OPTIMIZATION parameter is left blank. Added a check to print "none"
    for this case. For design, print the user input value of "D" or "V".
    Previously, the DESIGN OPTIMIZATION input was not printed in the
    output. (Request 516)

8.  The acceptable range of toe projections given in the ADDITIONAL
    INFORMATION Report now clarifies that range is for the given footing
    geometry. For footings on pedestals a second acceptable range of toe
    projections has been added that applies for both the footing
    geometry and the pedestal geometry. For footings on piles or
    caissons a second acceptable range of toe projections has been added
    that applies for both the footing geometry and the pile or caisson
    pattern. An issue that on very rare occasions resulted incorrect
    ranges has been corrected. (Request 518)

**[User Manual Revisions]{.underline}**

9.  The Revision Request Forms (User Manual and Word Template) do not
    refer to a PennDOT fax number. (Request 503)

10. Nomenclature has been updated in Chapter 3 to reflect the variables
    and information currently used. (Request 487)

**[Design Revisions]{.underline}**

11. Design Permit Loads have been added to the DLL command. This allows
    all relevant limit states to be considered in a single run of
    ABLRFD. Previously, separate runs were required for the PHL-93
    Design live load and the Permit live load (Controlling P-82 or
    P2016-13). Note that no design live load is considered for Strength
    V based on DM-4 Table 3.4.1.1P-3 -- Load Factors and Live Load
    Vehicles for Abutment/Retaining Walls. (Request 201)

12. Wind on substructure input parameters have been added to the Loads
    on Retaining Walls (LRT) Command to allow horizontal wind loads on
    the stem of retaining walls. (Request 509)

13. Design optimization for minimum footing volume has been enhanced to
    only consider trial footings with volumes less than the current
    minimum footing volume. (Request 515)

**[Engineering Assistant Revisions]{.underline}**

14. The figure names in Engineering Assistant's tabs and descriptions
    have been updated to be consistent with the figure names used in the
    User Manual. The User Manual has also been updated to include
    additional figures in Chapter 6. (Request 514)

**[Programmer Revisions]{.underline}**

15. The program has been made compatible with the forthcoming release of
    Engineering Assistant v3.0.0.0. Changes include:

1)  switching image formats from Enhanced Metafile (.emf file) to
    Portable Network Graphic (.png file) required by the new Engineer
    Assistant,

2)  associating a Tab Name with the current 3 letter tab abbreviation,

3)  resolving issues when setting floating-point precision on 64-bit
