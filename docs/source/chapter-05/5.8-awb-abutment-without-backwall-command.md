## 5.8 &emsp; AWB - Abutment Without Backwall Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                  **COMMAND DESCRIPTION**

       AWB       ABUTMENT WITHOUT BACKWALL - This command describes the geometry of an abutment without a backwall. The dimensions are shown in Figure 5.8-1. This command may only be specified once.
