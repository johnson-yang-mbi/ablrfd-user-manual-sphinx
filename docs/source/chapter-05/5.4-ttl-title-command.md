## 5.4 &emsp; TTL - Title Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                                                                                                                                          **COMMAND DESCRIPTION**

       TTL       TITLE - As many as ten TTL commands may be entered by the user. The first TTL command is printed in the header at the top of each output page. A maximum of ten TTL commands are printed on the first page of the output. If more than ten TTL commands are entered, the program will not use the TTL commands following the first ten TTL commands and a warning will be printed. The input file must have at least one TTL command.
