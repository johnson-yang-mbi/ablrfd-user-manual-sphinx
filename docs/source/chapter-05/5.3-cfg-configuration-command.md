## 5.3 &emsp; CFG - Configuration Command

| **KEYWORD** | **COMMAND DESCRIPTION** |
| :---: | :--- |
| CFG | CONFIGURATION - This command is used to set the control parameters for the characteristics of the printed output. An input file can have only one configuration command. |

| **Parameter** | **Description** | **Units** | **Lower Limit** | **Upper Limit** | **Default** |
| :--- | :--- | :---: | :---: | :---: | :---: |
| 1\. Lines per Page | Enter the maximum number of lines that will be allowed to be printed on each page of output. | \-- | 50 (E) | 83 (E) | 83 |
| 2\. Top Blank Lines per Page | Enter the number of blank lines that the program should leave at the top of each page of output to create a top margin. | \-- | 0 (E) | 5 (E) | 0 |
