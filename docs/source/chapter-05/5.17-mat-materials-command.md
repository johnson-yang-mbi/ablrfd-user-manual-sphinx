## 5.17 &emsp; MAT - Materials Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                             **COMMAND DESCRIPTION**

       MAT       MATERIALS - This command describes properties of materials used in the abutment or retaining wall. This command may only be specified once.
