## 5.13 &emsp; CAI - Caisson Command

  ------------- -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                       **COMMAND DESCRIPTION**

       CAI       CAISSON - This command describes caisson properties and individual caisson dimensions. Individual caisson dimensions are illustrated in Figure 5.12-1. This command may only be specified once.
