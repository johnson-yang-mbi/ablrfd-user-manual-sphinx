## 5.22 &emsp; CVR - Reinforcement Cover Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                                                                                 **COMMAND DESCRIPTION**

       CVR       REINFORCEMENT COVER - This command describes the clear concrete cover for reinforcement at various locations in the backwall, stem, and footing. Cover is illustrated in Figure 5.22-1. Exposure conditions for the backwall, stem, and footing are also described on MRD. This command may only be specified once.

^1^ For Analysis runs of Pile/Caisson Foundations, the default cover is the perpendicular reinforcement cover + the perpendicular reinforcement bar diameter. > For Design runs of Pile/Caisson Foundations, the default cover is the perpendicular reinforcement cover + the perpendicular reinforcement maximum bar diameter. The perpendicular reinforcement maximum bar diameter is the "Footing Maximum Diameter" parameter from the SPD command.
