## 5.10 &emsp; FTG - Footing Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                                                      **COMMAND DESCRIPTION**

       FTG       FOOTING - This command describes footing dimensions that apply to all structure and footing types. The footing dimensions are illustrated in Figures 5.6-1, 5.7-1, 5.8-1, or 5.9-1, depending on the structure type. This command may only be specified once.
