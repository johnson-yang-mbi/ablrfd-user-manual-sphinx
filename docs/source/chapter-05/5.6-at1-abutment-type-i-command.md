## 5.6 &emsp; AT1 - Abutment Type I Command

  ------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                     **COMMAND DESCRIPTION**

       AT1       ABUTMENT TYPE I - This command describes the geometry of an abutment with a backwall and a straight stem. The dimensions are shown in Figure 5.6-1. This command may only be specified once.
