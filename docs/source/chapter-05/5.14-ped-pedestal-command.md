  ------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                               **COMMAND DESCRIPTION**

       PED       PEDESTAL - This command describes pedestal properties and dimensions. Pedestal dimensions are illustrated in Figures 5.14-1 and 5.14-2. This command may be specified only once.
