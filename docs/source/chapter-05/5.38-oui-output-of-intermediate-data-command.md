## 5.38 &emsp; OUI - Output of Intermediate Data Command

  ------------- ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                                             **COMMAND DESCRIPTION**

       OUI       OUTPUT OF INTERMEDIATE DATA - This command is used to control the type of intermediate data reports, which can be requested by the user. These reports are applicable for both design and analysis. This command may only be specified once.
