## 5.21 &emsp; MRD - Miscellaneous Reinforcement Data Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                            **COMMAND DESCRIPTION**

       MRD       MISCELLANEOUS REINFORCEMENT DATA - This command describes miscellaneous reinforcement related data for both design and analysis. This command may only be specified once.
