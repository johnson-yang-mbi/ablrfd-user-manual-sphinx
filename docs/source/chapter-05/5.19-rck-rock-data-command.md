## 5.19 &emsp; RCK - Rock Data Command

  ------------- ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                                                                                                                                                  **COMMAND DESCRIPTION**

       RCK       ROCK DATA - This command describes properties of rock below the footing. This command may not be used if the SOI command has been specified and is not applicable for pile or caisson footings. This command must be specified for pedestal footing problems. Only one rock layer can be described. Figures 5.18-1 and 2 illustrate the dimensions described in this command. This command may only be specified once.
