## 5.18 &emsp; SOI - Soil Data Command

| **KEYWORD** | **COMMAND DESCRIPTION** |
| :---: | :--- |
| SOI | SOIL DATA - This command describes properties of soil below the footing. This command may not be used if the RCK command has been specified and is not applicable for pile, caisson, or pedestal footings. Figure 5.18-1 illustrates the dimensions described in this command. This command may only be specified once. |
