## 5.36 &emsp; OIN - Output of Input Command

| **KEYWORD** | **COMMAND DESCRIPTION** |
| :---: | :--- |
| OIN | OUTPUT OF INPUT - This command is used to control the type of input data reports which can be requested by the user. This command may only be specified once. |

| **Parameter** | **Description** | **Units** | **Lower Limit** | **Upper Limit** | **Default** |
| :--- | :--- | :---: | :---: | :---: | :---: |
| 1\. Input File Echo | An input file echo may be generated in the output. 0 - Do not print input file echo. 1 - Print input file echo. | \-- | 0 (E) | 1 (E) | 0 |
| 2\. Input Commands | The input data may be organized according to the command, with a short description for each data item. 0 - Do not print input commands. 1 - Print input commands. | \-- | 0 (E) | 1 (E) | 0 |
| 3\. Input Summary | A summary of the input data may be printed. 0 - Do not print input summary. 1 - Print input summary. | \-- | 0 (E) | 1 (E) | 1 |
