## 5.36 &emsp; OIN - Output of Input Command

  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------
   **KEYWORD**                                                                      **COMMAND DESCRIPTION**

       OIN       OUTPUT OF INPUT - This command is used to control the type of input data reports which can be requested by the user. This command may only be specified once.
  ------------- ---------------------------------------------------------------------------------------------------------------------------------------------------------------

+:-------------------:+:------------------------------------------------------------------------------------------------------:+:---------:+:---------:+:---------:+:-----------:+
| **PARAMETER**       | **DESCRIPTION**                                                                                        | **UNITS** | **LOWER** | **UPPER** | **Default** |
|                     |                                                                                                        |           |           |           |             |
|                     |                                                                                                        |           | **LIMIT** | **LIMIT** |             |
+---------------------+--------------------------------------------------------------------------------------------------------+-----------+-----------+-----------+-------------+
| 1\. Input File Echo | An input file echo may be generated in the output.                                                     | \--       | 0         | 1         | 0           |
|                     |                                                                                                        |           |           |           |             |
|                     | 0 - Do not print input file echo.                                                                      |           | \(E\)     | \(E\)     |             |
|                     |                                                                                                        |           |           |           |             |
|                     | 1 - Print input file echo.                                                                             |           |           |           |             |
+---------------------+--------------------------------------------------------------------------------------------------------+-----------+-----------+-----------+-------------+
| 2\. Input Commands  | The input data may be organized according to the command, with a short description for each data item. | \--       | 0         | 1         | 0           |
|                     |                                                                                                        |           |           |           |             |
|                     | 0 - Do not print input commands.                                                                       |           | \(E\)     | \(E\)     |             |
|                     |                                                                                                        |           |           |           |             |
|                     | 1 - Print input commands.                                                                              |           |           |           |             |
+---------------------+--------------------------------------------------------------------------------------------------------+-----------+-----------+-----------+-------------+
| 3\. Input Summary   | A summary of the input data may be printed.                                                            | \--       | 0         | 1         | 1           |
|                     |                                                                                                        |           |           |           |             |
|                     | 0 - Do not print input summary.                                                                        |           | \(E\)     | \(E\)     |             |
|                     |                                                                                                        |           |           |           |             |
|                     | 1 - Print input summary.                                                                               |           |           |           |             |
+---------------------+--------------------------------------------------------------------------------------------------------+-----------+-----------+-----------+-------------+
