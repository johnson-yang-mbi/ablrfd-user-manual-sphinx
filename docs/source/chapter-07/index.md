# Chapter 7 — Output Description

This chapter describes the reports that are generated by the program. Section 7.1 addresses the general information about the output. The cover page is described in section 7.2. Sections 7.3, 7.4 and 7.5 describe the reports associated with the OIN (Section 5.36), OUR (Section 5.37), and OUI (Section 5.38) commands respectively. Section 7.5.7 contains the formats for all of the tables used by the program. The chapter concludes with some remarks about the error reporting in Sections 7.6.24 and 7.8.

The reports are output in the following order (section identified in parenthesis): Input Summary (7.3); Footing Additional Information (7.4.1); Pile Pattern (7.4.2); Output Legend (7.4.3); Unfactored Loads (7.5.1); Load Factors (7.5.2); Factored Forces (7.4.4); Footing Stability (7.4.5); Internal Footing Forces (7.5.5); Controlling Footing Forces (7.4.6); Moment/Axial Interaction (7.5.4); Footing Flexure (7.4.7); Crack Control (7.4.8); Reinforcement Summary (7.4.9); Shear Results (7.4.10); Reinforcement Design Details (7.4.11); and, Optimum Design Details (7.4.12).
