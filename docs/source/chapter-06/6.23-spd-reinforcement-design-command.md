## 6.23 &emsp; SPD - REINFORCEMENT DESIGN COMMAND

### 6.23.5 User Requested Minimum Bar Spacing & 6.23.6 Bar Spacing Increment

> The User Requested Minimum Bar Spacing and the Bar Spacing Increment are used to control what bar spacings are allowable during a design run. The following table shows how different combinations of these two parameters will affect bar spacing during design runs.

| User Requested Minimum Bar Spacing (in.) | Bar Spacing Increment (in.) | Resulting Bar Spacings (in.) |
| --- | --- | --- |
| 6.0 | 3.0 | 6, 9, 12, 15, 18 |
| 6.0 | 2.0 | 6, 8, 10, 12, 14, 16, 18 |
| 2.5 | 3.0 | 2.5, 5.5, 8.5, 11.5, 14.5, 17.5 |
| 4.0 | 5.0 | 4, 9, 14 |

> Because the maximum allowable spacing permitted by DM-4 is 18 in, the spacings computed by the program are limited to 18 in or less.
