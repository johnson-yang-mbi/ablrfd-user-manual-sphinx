## 6.27 &emsp; SRA - STEM REINFORCEMENT AREAS COMMAND

**Figure 6.27-1 is an illustrated example of how the stem rebar layout is described in terms of the SRA command syntax.**

**Figure 6.27-1 SRA Example**

> Description:
>
> \* #8 @ 12\" spacing at 0\" offset (by definition) has 7\' length
>
> \* #5 @ 12\" spacing at 6\" offset (relative to #8) has 4\' length
>
> SRA Input:
>
> #8 \-- Area of bar = 0.79 in{superscript}`2`; Diameter of bar = 1.0 in.
>
> #5 \-- Area of bar = 0.31 in{superscript}`2`; Diameter of bar = 0.625 in.
>
> From footing top to 4\' - Total area per unit width is 1.10 in{superscript}`2` (#8 + #5)
>
> From 4\' to 7\' - Total area per unit width is 0.79 in{superscript}`2` (#8)
>
> Consequently: SRA 1.10, 4, 1.0, 0.79, 7, 1.0
>
> (Equivalent SRB Command syntax: SRB 8, 12., ,7., 5, 12., 6., 4. )
